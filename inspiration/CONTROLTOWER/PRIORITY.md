Control Tower — implementation priorities
1. Phase 1 — Warehouse visual
 
   Build the complete isometric warehouse, conveyor belts, stations, labels and responsive layout.
   Must have
2. Phase 2 — Real data integration
 
   Connect existing analytics events, timestamps and event types. No fabricated live events.
   Must have
3. Phase 3 — Moving packages
 
   Animate events through their corresponding stations. Show exception routing.
   Must have
4. Phase 4 — Interactive inspection
 
   Click a package, inspect its event, timestamp, source and status.
   Important
5. Phase 5 — Advanced control room
 
   Historical playback, filters, throughput charts, bottleneck detection and advanced data-quality views.
