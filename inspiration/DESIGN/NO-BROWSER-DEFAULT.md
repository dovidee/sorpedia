Sørpedia — Browser Default UI Elimination

Audit the entire application and eliminate inconsistent, unstyled browser-default UI elements.

This includes:

1. Form controls

Replace default checkboxes with custom-designed Sørpedia checkboxes.
Replace default radio buttons with custom radio controls.
Style select elements and dropdown indicators.
Remove number-input spinner arrows where appropriate.
Standardize text inputs, search fields and textareas.
Design consistent focus, hover, active, disabled and checked states.

2. Lists and counters

Remove unwanted default ordered-list numbering.
Remove unwanted default bullet markers.
Replace browser-default counters with intentional component styling.
Preserve numbering and bullets when they communicate meaningful information.

3. Buttons and interactive elements

Eliminate inconsistent browser-default button appearance.
Standardize button dimensions, borders, typography and states.
Design consistent dropdown arrows and disclosure indicators.

4. Global normalization

Audit browser-default margins, padding, borders and typography.
Establish consistent box-sizing.
Normalize form control appearance.
Ensure consistent rendering across Chrome, Safari and Firefox.

Important: Do not indiscriminately remove accessibility features. Preserve visible keyboard focus indicators, semantic HTML, keyboard navigation and screen-reader functionality.

Do not use CSS resets as an excuse to remove useful browser functionality.

Every custom control must remain fully functional, accessible and responsive.

The final interface must look deliberately designed rather than like unstyled HTML.
