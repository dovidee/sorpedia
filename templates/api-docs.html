Product knowledge API

Loading the API description …

  • Base URL/api/v1. Product IDs are the web shop's own IDs, so a shop can call the API with the IDs it already has.
  • ConfirmedA specification is confirmed only when it is the verified version from the store or staff. Derived and buyer values are never confirmed.
  • CertainA related product is certain only when the relation is documented. Rule based and assumed relations say so.
  • UnknownMissing values are listed under unknown, never guessed.
  • CachingEvery answer has an ETag and Cache-Control: public, max-age=60. Send If-None-Match to get 304 when nothing changed.
  • NavigationEvery body carries _links; collections also send an RFC 8288 Link header and X-Total-Count.
  • AccessNo key, no cookie, no session. CORS is open. Reading uses GET, HEAD and OPTIONS; the only POST is a question to the product assistant, limited to 60 per 10 minutes per client. Of those, 10 may be read by the language model; the rest are read by rules, and the answer is the same kind.
  • AssistantThe server writes every product answer from the catalogue. A local language model only reads the question into fixed fields, which the server checks; it writes no answer text. Greetings and questions about the assistant get a fixed answer. notice says how the question was read.
  • Not in the APIStock, orders, users, internal IDs and staff tools. Prices are the shop's own and included for display.

Errors

Errors are RFC 9457 problem details (application/problem+json) with type, title, status and detail.

400 Bad request
A query parameter has a value the resource does not accept. detail names the parameter and the allowed values.
404 Not found
No product, theme or path with that name.
405 Method not allowed
The method is not allowed on this path. The Allow header lists the methods that are.
406 Not acceptable
The Accept header rules out JSON.
415 Unsupported media type
A question must be sent as application/json.
429 Too many requests
The question limit for this client is used up. Retry-After says how many seconds to wait.
500 Internal error
Something failed on the server. detail carries a reference for the log.
